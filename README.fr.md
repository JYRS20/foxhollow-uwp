# Foxhollow UWP

Foxhollow : un port natif de Star Fox Adventures basé sur la décompilation SFA et Aurora.

> [!IMPORTANT]
> Vous devez fournir votre propre copie du jeu. Aucun disque, sauvegarde ou pack de textures n’est inclus.

## Installation

1. Téléchargez la version **0.5.8.17** depuis [Releases](https://github.com/JYRS20/foxhollow-uwp/releases).
2. Installez l’**APPX x64** via Device Portal et ajoutez **VCLibs x64** si nécessaire.
3. Dans Dev Home, choisissez **App type → Game**.
4. Connectez une clé USB avec votre **ISO, RVZ ou GCM**, choisissez **CHOISIR LE JEU**, puis **JOUER**.

Le disque est lu directement depuis USB : **gardez la clé connectée pendant le jeu**.

Disques compatibles : USA **GSAE01** et PAL **GSAP01**, révisions 0 et 1 ; Japon **GSAJ01**, révision 0.

## Paramètres et textures

Appuyez sur **View** pendant le jeu pour ouvrir la barre. Les paramètres incluent **720p/1080p**, **4:3/16:9**, la langue du jeu PAL et un compteur FPS. Choisissez **espagnol, anglais, français, allemand ou italien** dans **Paramètres → Langue du menu**.

Dans le menu principal, ouvrez **TEXTURES** et sélectionnez le **ZIP** du pack sur USB. Pendant le jeu, utilisez **View → Textures** pour l’activer ou le désactiver.
