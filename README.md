# Foxhollow UWP

Port no oficial de **Star Fox Adventures** para **Xbox Series X|S en Developer Mode**, basado en [Foxhollow](https://github.com/JackPriceBurns/foxhollow). También permite probar el APPX en Windows.

> [!IMPORTANT]
> Necesitas tu propia copia del juego. No se incluyen discos, partidas ni packs de texturas.

## Instalación

1. Descarga la versión **0.5.8.16** desde [Releases](https://github.com/JYRS20/foxhollow-uwp/releases).
2. Instala el **APPX x64** mediante Xbox Device Portal y añade **VCLibs x64** si se solicita.
3. En Dev Home, configura **App type → Game**.
4. Conecta una USB con tu **ISO, RVZ o GCM**, abre **SELECCIONAR JUEGO** y después **JUGAR**.

El disco se lee directamente desde USB: **mantén la unidad conectada mientras juegas**.

Discos admitidos: USA **GSAE01** y PAL **GSAP01**, revisiones 0 y 1; Japón **GSAJ01**, revisión 0.

## Configuración y texturas

Pulsa **View** durante la partida (**F1** en Windows) para abrir la barra. Incluye ajustes de **720p/1080p**, **4:3/16:9**, idioma PAL y contador de FPS.

Para instalar un pack, selecciona su **ZIP** desde **TEXTURAS** en el menú principal. Se guarda en Xbox y el juego y el audio se pausan durante la preparación. Puedes activarlo o desactivarlo desde la barra durante la partida.
